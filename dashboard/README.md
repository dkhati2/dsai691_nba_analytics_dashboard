# Dashboard (Metabase)

Connect Metabase to the indexed Postgres database and build one dashboard
that walks through all four narrative layers in order:

1. League three-point rate over time (line chart)
2. Team ranking vs. league average, selectable by season (bar/table)
3. Early adopters vs. win percentage, current + next 2 seasons (scatter/line)
4. Shot selection vs. roster height by era (scatter, colored by era)

Export the dashboard definition (Metabase → Settings → Export) into this
folder once built, along with a few annotated screenshots for the final
presentation.
